# 鲸鱼娘原生动作绑定与 PPL 联动（dev.12）

## 目标

让用户导入的 DyberPet 原生逐帧动作包可以由鲸鱼娘自己的 PPL 状态和交互状态驱动。动作库与角色启用分离；导入不等于绑定。

## 用户流程

1. 通过「更多 → 角色与外观 → 动作包预览」选择本地 DyberPet 目录。
2. 预览动作并显式导入到本地动作库。
3. 在本地动作库中打开已导入的动作包。
4. 配置日常待机、思考、回复、摸摸、休息等核心动作；可展开 PPL 情绪映射配置开心、害羞、认真、疑惑、不开心、紧张、无奈和憧憬动作。
5. 勾选素材确认项：确认素材外观与鲸鱼娘一致，且拥有使用权。
6. 点击「启用并绑定到鲸鱼娘」。绑定只建立动作映射，不改动 PPL、好感度、关系、聊天或记忆。
7. 需要恢复原有立绘时，点击「解除绑定」。卸载当前绑定的动作包也会自动解除绑定。

## 动作解析优先级

- 思考中：`thinking`，没有单独映射时回退到 `idle`。
- 摸摸：`patting`，其次回退到当前表情动作，最后回退到 `idle`。
- 回复后：`responding`，其次回退到当前 PPL 表情动作，最后回退到 `idle`。
- 角色疲劳达到 PPL 阈值且配置了 `resting` 时，待机状态优先采用休息动作。
- 其他待机状态：按 PPL 当前表情选择对应映射；没有映射时使用 `idle`。
- 绑定不存在、未确认或动作引用缺失时，客户端继续使用原有 Whale 表情立绘，不会尝试猜测或生成帧。

## 安全与资源边界

- 绑定动作前要求显式确认角色形象一致和素材使用权；系统不声称具备自动角色身份识别能力。
- Kitty/ChrisKitty 示例只能测试播放器，不应作为鲸鱼娘素材绑定。
- 原生动作帧仍由 Host 私有动作库提供；URL 使用 pack UUID 与相对帧路径，响应为私有不可变缓存，并在每次首次读取时校验 SHA-256。
- 客户端只预加载当前动作的前 12 帧，后续帧通过浏览器缓存按需读取，避免一次把整包图片加载到内存。
- 系统减少动态效果设置会暂停原生逐帧播放并回到该动作首帧，同时继续遵循 CSS 减少动态效果规则。
- 解除绑定恢复原有立绘；卸载动作包要求二次确认，删除动作包时数据库外键同步清理绑定。

## 存储与审计

- `motion_pack_bindings` 每个角色仅保留一个当前绑定，记录动作映射、身份确认标志和更新时间。
- 绑定与解除绑定写入 SQLite 审计事件；动作包仍按原有内容哈希去重、帧 SHA-256 校验和私有 assets 目录持久化。
- 动作包进入正常插件备份；绑定配置保存在 SQLite 中，与动作帧一起备份恢复。

## 验证

- 存储测试：身份确认必需、动作引用校验、必需 idle、关闭重开持久化、显式解除绑定、卸载级联解除绑定。
- Host 测试：绑定/查询/解除绑定、public view 映射、帧缓存、卸载后绑定清理。
- Client 测试：PPL/交互状态解析、动作回退、身份未确认时不启用、经典 DSH 脚本、减少动态效果和有界帧预加载。
- DSH Desktop 0.2.2-rc.1 实机验收仍需验证实际帧播放、动作切换和退出绑定后的立绘恢复。
